# 04-Graph-Algorithms (Complete 36 Problems)

> **Category Problem Count**: 36 Problems  
> **Language**: Modern C++ (C++17/C++20 with Fast I/O, No Java)

## 📌 Overview

Complete graph theory: BFS/DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal MST with DSU, Topological Sort, Kosaraju/Tarjan SCC, 2-SAT, Hierholzer's Eulerian Trails, Bitmask DP, Warnsdorff's Knight's Tour, and Dinic's Maximum Flow / Minimum Cut.
